# Create your GitHub account

Visit https://github.com/signup, create a personal account and verify your email. Use your professional name for the username if available, such as LaurentHolleville. A free personal account is sufficient for this portfolio.

# GitHub portfolio setup

Suggested repository name: `insurance-operations-power-bi`

Suggested description: `Power BI portfolio using synthetic insurance operations data: executive KPIs, operational performance, customer experience and quality.`

1. Extract the ZIP on your computer.
2. Sign in to GitHub and create a new repository with the name above. Choose Public so recruiters can view it.
3. Upload the extracted contents, preserving the screenshots folder. Upload README.md, DAX_Measures.md, Operational_Report.pbix, the screenshots folder and the supporting Markdown documents. Upload the contents rather than just the ZIP.
4. Confirm the repository homepage displays the README and its images.
5. Copy the repository URL into your LinkedIn project and relevant resume project entry.

The PBIX is an editable Desktop report; the README is the accessible static preview for visitors. No interactive hosted Power BI report is included.
